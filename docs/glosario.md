# Glosario de Términos

Para asegurar una comunicación clara, definimos los conceptos base del ecosistema RackVR:

* **KVM (Kernel-based Virtual Machine)**: Tecnología de virtualización de código abierto integrada en Linux.
* **Libvirt**: API y demonio para gestionar plataformas de virtualización.
* **JWT (JSON Web Token)**: Estándar para transmitir información de identidad de forma segura entre el cliente y el servidor.
* **RBAC (Role-Based Access Control)**: Método de restringir acceso a recursos basado en el rol del usuario.
* **Datastore**: Repositorio de almacenamiento lógico donde residen los discos virtuales.
* **QCOW2**: Formato de imagen de disco que soporta aprovisionamiento dinámico (*Thin Provisioning*).
* **noVNC**: Cliente VNC basado en HTML5 que permite ver la consola de la VM en el navegador.
