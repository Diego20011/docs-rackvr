# Interfaz de Usuario y Dashboard

RackVR proporciona un entorno visual centralizado para la gestión de la infraestructura.

## Panel de Control
El dashboard principal ofrece una vista en tiempo real de:
* **Estado de Salud**: Indicadores de conectividad de los nodos físicos.
* **Métricas de Consumo**: Gráficas de utilización de CPU y RAM.
* **Inventario**: Acceso directo a la lista de máquinas virtuales.
![Diagrama de Arquitectura de RackVR](/img/Dashboard_rackvr.png)
## Interacción con Instancias
A través de la interfaz, los usuarios pueden acceder a la consola **noVNC** y ejecutar comandos de ciclo de vida (Start, Stop, Pause) de forma gráfica.
